
# 🔐 ACL - Access Control Lists no Linux

> **Tags:** #linux #acl #permissoes #seguranca #setfacl #getfacl

---

## 📌 Visão Geral

**ACLs (Access Control Lists)** fornecem um controle de permissões mais granular do que as permissões tradicionais (proprietário, grupo, outros).

🎯 **Objetivo:** Atribuir permissões específicas a usuários e grupos que não são o proprietário ou o grupo principal do arquivo.

---

## 📊 Permissões Tradicionais vs ACLs

### Permissões Tradicionais

- **Limitação:** Apenas um proprietário, um grupo e "outros".
- **Exemplo:** `rwxr-xr--` (Proprietário: rwx, Grupo: r-x, Outros: r--)

---

### ACLs

- **Flexibilidade:** Permite definir permissões para múltiplos usuários e grupos específicos.
- **Exemplo:**
  - Proprietário: rwx
  - Grupo: r-x
  - Outros: r--
  - Usuário "joao": rw-
  - Grupo "contabilidade": r-x

---

**Descrição:** O pacote `acl` fornece as ferramentas `setfacl` e `getfacl`.

## 🔧 Definindo ACLs (setfacl)

**Descrição:** Define ou modifica as ACLs de um arquivo ou diretório.

**Sintaxe:** `sudo setfacl [opções] <arquivo/diretório>`

### Opções Comuns

| Opção | Descrição |
|-------|-----------|
| `-m` | Modificar/adicionar ACLs |
| `-x` | Remover ACLs específicas |
| `-b` | Remover todas as ACLs |
| `-R` | Recursivo (para diretórios) |
| `-d` | Definir ACLs padrão para novos arquivos em um diretório |

---

### Adicionar/Modificar ACLs (`-m`)

**Sintaxe:** `sudo setfacl -m [u|g]:<nome>:<permissões> <arquivo/diretório>`

- `u`: Usuário
- `g`: Grupo
- `<nome>`: Nome do usuário ou grupo
- `<permissões>`: `r` (leitura), `w` (escrita), `x` (execução)

### Máscara (mask)

**Descrição:** A `mask` define as permissões **máximas efetivas** que um usuário ou grupo pode ter através de uma ACL.

- Se uma ACL concede `rwx` mas a `mask` é `rw-`, a permissão efetiva será `rw-`.
- A `mask` é atualizada automaticamente ao adicionar ACLs.
