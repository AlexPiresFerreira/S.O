## 📚 Documentação Oficial e Manuais

- **Kernel.org:** [www.kernel.org](https://www.kernel.org/)
  - O site oficial do kernel Linux.
- **GNU.org:** [www.gnu.org](https://www.gnu.org/)
  - Projeto GNU, com documentação para utilitários como Bash, GCC, etc.
- **Linux Foundation:** [www.linuxfoundation.org](https://www.linuxfoundation.org/)
  - Organização que promove o Linux e projetos open source.
- **Man Pages Online:** [man7.org](https://man7.org/)
  - Acesso online a todas as páginas de manual do Linux.
- **The Linux Documentation Project (TLDP):** [tldp.org](https://tldp.org/)
  - Coleção de HOWTOs, guias e FAQs sobre Linux.

## 🛠️ Ferramentas Online e Utilitários

- **CyberChef:** [gchq.github.io/CyberChef/](https://gchq.github.io/CyberChef/)
  - "Canivete suíço" para manipulação de dados (codificação, decodificação, criptografia).
- **Shodan:** [www.shodan.io](https://www.shodan.io/)
  - Motor de busca para dispositivos conectados à internet (IoT, servidores).
- **VirusTotal:** [www.virustotal.com](https://www.virustotal.com/)
  - Analisa arquivos e URLs em busca de malware.
- **Shellcheck:** [www.shellcheck.net](https://www.shellcheck.net/)
  - Linter para scripts Bash (ajuda a encontrar erros).
- **Regex101:** [regex101.com](https://regex101.com/)
  - Testador e explicador de Expressões Regulares.
- **Iperf.fr:** [iperf.fr](https://iperf.fr/)
  - Ferramenta para medir a largura de banda da rede.
- **Cockpit Project:** [cockpit-project.org](https://cockpit-project.org/)
  - Interface web para gerenciamento de servidores Linux.
- **HeidiSQL:** [www.heidisql.com](https://www.heidisql.com/)
  - Cliente GUI para MySQL/MariaDB/PostgreSQL (Windows).
- **DBeaver:** [dbeaver.io](https://dbeaver.io/)
  - Cliente GUI universal para bancos de dados.
