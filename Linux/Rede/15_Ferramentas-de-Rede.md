
# 🛠️ Ferramentas de Rede no Linux

> **Tags:** #linux #rede #ferramentas #diagnostico #ping #traceroute #netstat #ss #nmap

## 📌 Visão Geral

Ferramentas de rede são essenciais para diagnosticar problemas de conectividade, monitorar o tráfego e realizar varreduras.

🎯 **Objetivo:** Utilizar as principais ferramentas para análise e troubleshooting de rede.

---

## 🔍 Diagnóstico Básico

### ping

**Descrição:** Testa a conectividade com um host enviando pacotes ICMP Echo Request.

**Sintaxe:** `ping [opções] <host>`

**Opções comuns:**
- `-c <count>`: Número de pacotes a enviar.
- `-I <interface>`: Especificar interface de origem.
- `-s <size>`: Tamanho do pacote.
- `-t <ttl>`: Time To Live.

**Exemplos:**

bash

#### Pingar host

ping google.com

#### Pingar 4 vezes

ping -c 4 192.168.1.1

#### Pingar de uma interface específica

ping -I eth0 8.8.8.8
