
# 📈 Monitoramento de Rede no Linux

> **Tags:** #linux #rede #monitoramento #trafego #tcpdump #wireshark #iptraf #darkstat #snmp

---

## 📌 Visão Geral

Monitorar a rede é crucial para identificar gargalos, detectar anomalias, solucionar problemas e garantir a segurança.

🎯 **Objetivo:** Utilizar ferramentas para capturar, analisar e visualizar o tráfego de rede em tempo real ou offline.

---

## 🔍 Captura e Análise de Pacotes

### tcpdump

**Descrição:** Ferramenta de linha de comando para captura e análise de pacotes.

**Ver detalhes completos em:** [[Tcpdump]]

**Exemplos:**

bash
#### Capturar todo o tráfego na interface eth0

sudo tcpdump -i eth0
#### Capturar tráfego HTTP e exibir em ASCII

sudo tcpdump -i eth0 -A 'tcp port 80'
#### Salvar captura em arquivo PCAP

sudo tcpdump -i eth0 -w capture.pcap
#### Ler captura de arquivo e filtrar por host

tcpdump -r capture.pcap host 192.168.1.10
