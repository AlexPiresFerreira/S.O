# 💾 Gerenciamento de Discos no Linux

> **Tags:** #linux #discos #particoes #fdisk #mkfs #mount #lvm #fstab

---

## 📌 Visão Geral

Gerenciar discos e partições é essencial para organizar o armazenamento, otimizar o desempenho e garantir a integridade dos dados.

🎯 **Objetivo:** Particionar, formatar, montar e gerenciar volumes lógicos.

---

## 📊 Nomenclatura de Discos

### Discos Físicos

- **SATA/SCSI/NVMe:** `/dev/sda`, `/dev/sdb`, `/dev/nvme0n1`
- **IDE (legado):** `/dev/hda`, `/dev/hdb`

---

### Partições

- **Numeração:** `/dev/sda1`, `/dev/sda2`, `/dev/nvme0n1p1`
- **Partições primárias:** 1-4
- **Partições lógicas:** 5+

---

### fdisk (MBR - Master Boot Record)

**Descrição:** Ferramenta para particionar discos com tabela MBR.

- `m`: Ajuda
- `p`: Imprimir tabela de partições
- `n`: Criar nova partição
- `d`: Deletar partição
- `t`: Mudar tipo de partição
- `w`: Salvar mudanças e sair
- `q`: Sair sem salvar

### gdisk (GPT - GUID Partition Table)

**Descrição:** Ferramenta para particionar discos com tabela GPT (moderno, recomendado para discos > 2TB).

**Sintaxe:** `sudo gdisk /dev/sdx`

**Comandos interativos:**
- `?`: Ajuda
- `p`: Imprimir tabela de partições
- `n`: Criar nova partição
- `d`: Deletar partição
- `t`: Mudar tipo de partição
- `w`: Salvar mudanças e sair
- `q`: Sair sem salvar

## 📝 Formatação de Partições (mkfs)

**Descrição:** Cria um sistema de arquivos em uma partição.

**Sintaxe:** `sudo mkfs.<filesystem_type> /dev/sdxY`

**Tipos de sistemas de arquivos:**
- `ext4`: Padrão Linux (recomendado)
- `ext3`, `ext2`: Versões anteriores
- `xfs`: Alta performance, usado em servidores
- `btrfs`: Moderno, com recursos avançados (snapshots)
- `ntfs`: Windows
- `fat32`: Compatível com Windows/macOS/Linux

### /etc/fstab (Filesystem Table)

**Descrição:** Configura montagens automáticas de sistemas de arquivos no boot.

**Formato:**
`device_or_UUID mount_point filesystem_type options dump_freq fsck_pass`

**Exemplo:**
```

# /etc/fstab: static file system information.

#

UUID=a1b2c3d4-e5f6-7890-1234-567890abcdef / ext4 errors=remount-ro 0 1 /dev/sdb1 /mnt/meudisco ext4 defaults 0 2

```
**Opções comuns:**
- `defaults`: `rw,suid,dev,exec,auto,nouser,async`
- `noauto`: Não montar no boot (montagem manual)
- `ro`: Somente leitura
- `rw`: Leitura e escrita
- `user`: Usuários comuns podem montar/desmontar
- `nouser`: Apenas root pode montar/desmontar
- `nofail`: Continuar boot mesmo se a montagem falhar

## 🗄️ LVM (Logical Volume Manager)

**Descrição:** Gerenciamento flexível de espaço em disco, permitindo redimensionar partições dinamicamente.

**Componentes:**
1. **Physical Volume (PV):** Discos ou partições físicas.
2. **Volume Group (VG):** Agrupamento de um ou mais PVs.
3. **Logical Volume (LV):** Partições virtuais criadas dentro de um VG.
