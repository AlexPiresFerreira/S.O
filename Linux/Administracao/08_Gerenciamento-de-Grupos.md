# 👥 Gerenciamento de Grupos no Linux

> **Tags:** #linux #grupos #administracao #seguranca #groupadd #groupdel #gpasswd

---

## 📌 Visão Geral

Grupos são usados para organizar usuários e simplificar o gerenciamento de permissões em arquivos e diretórios.

🎯 **Objetivo:** Criar, modificar e deletar grupos, e adicionar/remover usuários de grupos.

---

## 📊 Arquivos de Configuração

### /etc/group

**Descrição:** Armazena informações sobre os grupos do sistema.

**Formato:** `group_name:password_placeholder:GID:members`

**Exemplo:**

root:x:0: adm:x:4:sysadmin,usuario sudo:x:27:usuario usuario:x:1000:

**Campos:**
1. **group_name:** Nome do grupo.
2. **password_placeholder:** `x` indica que a senha está em `/etc/gshadow` (usado para grupos com senha).
3. **GID (Group ID):** Identificador numérico único do grupo.
   - `0`: Grupo root.
   - `1-999`: Grupos de sistema.
   - `1000+`: Grupos comuns.
4. **members:** Lista de usuários que são membros suplementares deste grupo (separados por vírgula).

---

### /etc/gshadow

**Descrição:** Armazena senhas criptografadas de grupos e administradores de grupo.

**Apenas root pode ler este arquivo.**

---

## ➕ Criar Grupos (groupadd)

**Sintaxe:** `sudo groupadd [opções] <group_name>`

**Opções comuns:**
- `-g <GID>`: Definir GID.
- `-r`: Criar grupo de sistema (GID < 1000).
