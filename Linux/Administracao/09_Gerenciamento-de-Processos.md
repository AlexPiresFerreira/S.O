# ⚙️ Gerenciamento de Processos no Linux

> **Tags:** #linux #processos #administracao #ps #top #kill #nice #systemd

---

## 📌 Visão Geral

Um **processo** é uma instância de um programa em execução. Gerenciar processos é crucial para monitorar a saúde do sistema, otimizar recursos e solucionar problemas.

🎯 **Objetivo:** Listar, monitorar, controlar e encerrar processos.

---

## 📊 Informações de Processos

### PID (Process ID)

**Descrição:** Um número único que identifica cada processo em execução.

---

### PPID (Parent Process ID)

**Descrição:** O PID do processo que iniciou o processo atual.

---

### TTY (Teletypewriter)

**Descrição:** O terminal ou console associado ao processo. `?` indica que não há terminal.

---

### TIME (CPU Time)

**Descrição:** Tempo total de CPU usado pelo processo.

---

### CMD (Command)

**Descrição:** O comando que iniciou o processo.

---

## 🔍 Listando Processos (ps)

**Descrição:** Exibe um snapshot dos processos em execução.

### Opções Comuns

| Opção | Descrição |
|-------|-----------|
| `-e` | Todos os processos |
| `-f` | Formato completo (full format) |
| `-a` | Processos de todos os usuários |
| `-u` | Formato amigável ao usuário |
| `-x` | Processos sem terminal |
| `aux` | Combinação popular (all users, user-oriented, no tty) |
| `ef` | Formato completo, árvore de processos |
| `--forest` | Exibe processos em formato de árvore |

---

### Exemplos

bash

#### Processos do usuário atual

ps
#### Todos os processos (snapshot)

ps -e
#### Formato completo para todos os processos

ps -ef
#### Processos de todos os usuários (popular)

ps aux
#### Processos em formato de árvore

ps fax

# Processos com PID e PPID

ps -o pid,ppid,cmd


**Informações principais:**
- **Load Average:** Carga média do sistema (últimos 1, 5, 15 minutos).
- **Tasks:** Total de processos, rodando, dormindo, parados, zumbis.
- **CPU(s):** Uso da CPU (user, system, nice, idle, iowait, irq, softirq, steal).
- **Mem:** Memória RAM (total, free, used, buff/cache).
- **Swap:** Memória Swap (total, free, used, avail).

**Colunas de Processos:**
- **PID:** Process ID.
- **USER:** Usuário proprietário.
- **PR:** Prioridade (Priority).
- **NI:** Nice value (Nice).
- ****VIRT:** Memória virtual usada.
- **RES:** Memória residente (RAM) usada.
- **SHR:** Memória compartilhada.
- **S:** Status (R=running, S=sleeping, Z=zombie, T=stopped).
- **%CPU:** Uso de CPU.
- **%MEM:** Uso de memória.
- **TIME+:** Tempo de CPU acumulado.
- **COMMAND:** Comando.

**Comandos no `top`:**
- `k`: Matar processo (kill).
- `r`: Renice processo.
- `P`: Ordenar por %CPU (padrão).
- `M`: Ordenar por %MEM.
- `T`: Ordenar por TIME+.
- `q`: Sair.

## 🛑 Controlando Processos (kill / killall / pkill)

### kill

**Descrição:** Envia sinais para processos.

**Sintaxe:** `kill [opções] <PID>`

**Sinais Comuns:**
- `1` (SIGHUP): Recarregar configuração.
- `2` (SIGINT): Interrupção (Ctrl+C).
- `9` (SIGKILL): Encerrar processo **imediatamente** (não pode ser ignorado).
- `15` (SIGTERM): Encerrar processo **graciosamente** (pode ser ignorado).

## ⚖️ Prioridade de Processos (nice / renice)

### nice

**Descrição:** Inicia um processo com uma prioridade diferente.

**Valor Nice:** -20 (maior prioridade) a 19 (menor prioridade). Padrão é 0.

## 🔍 Localizando Processos (pgrep)

**Descrição:** Busca PIDs de processos por nome ou outros atributos.

**Sintaxe:** `pgrep [opções] <pattern>`

**Opções:**
- `-u <user>`: Processos de um usuário.
- `-l`: Lista nome e PID.
- `-n`: Processo mais recente.
- `-o`: Processo mais antigo.
- `-f`: Busca na linha de comando completa.
