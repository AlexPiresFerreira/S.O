# 📦 Gerenciamento de Pacotes no Linux

> **Tags:** #linux #pacotes #apt #yum #dnf #rpm #dpkg #instalacao #atualizacao

---

## 📌 Visão Geral

Gerenciadores de pacotes simplificam a instalação, atualização, configuração e remoção de software no Linux.

🎯 **Objetivo:** Dominar as ferramentas de gerenciamento de pacotes para diferentes distribuições.

---

## 📊 Conceitos

### Pacote

**Descrição:** Um arquivo compactado que contém o software, suas dependências, metadados e scripts de instalação.

---

### Repositório

**Descrição:** Um servidor centralizado que armazena pacotes e metadados.

---

### Dependência

**Descrição:** Outros pacotes que um software requer para funcionar corretamente.

---

## 🐧 Gerenciadores de Pacotes por Família

### 1️⃣ Debian/Ubuntu (APT / DPKG)

#### DPKG (Debian Package)

**Descrição:** Ferramenta de baixo nível para gerenciar pacotes `.deb`.

**Sintaxe:** `sudo dpkg [opções] <package_name>`

**Exemplos:**

bash

#### Instalar pacote .deb (não resolve dependências)

sudo dpkg -i pacote.deb

#### Remover pacote

sudo dpkg -r nome_do_pacote

#### Remover pacote e arquivos de configuração

sudo dpkg -P nome_do_pacote

#### Listar todos os pacotes instalados

dpkg -l

#### Verificar status de um pacote

dpkg -s nome_do_pacote

#### Listar arquivos de um pacote

dpkg -L nome_do_pacote

#### Identificar qual pacote possui um arquivo

dpkg -S /usr/bin/ls


---

**Sintaxe:** `sudo apt [opções] <package_name>`

## 🛠️ Instalação a Partir do Código-Fonte

**Descrição:** Compilar software diretamente do código-fonte.

**Passos comuns:**
1. **Baixar:** `wget <url_do_tarball>`
2. **Extrair:** `tar -xvf <arquivo.tar.gz>`
3. **Navegar:** `cd <diretorio_do_codigo>`
4. **Configurar:** `./configure` (verifica dependências e prepara a compilação)
5. **Compilar:** `make`
6. **Instalar:** `sudo make install`
7. **Remover (opcional):** `sudo make uninstall`

**Vantagens:**
- Versão mais recente.
- Otimização para o sistema.

**Desvantagens:**
- Não gerencia dependências automaticamente.
- Mais complexo.
- Dificuldade em desinstalar.
