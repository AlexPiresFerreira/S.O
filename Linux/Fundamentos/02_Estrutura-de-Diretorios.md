
# 📂 Estrutura de Diretórios do Linux

> **Tags:** #linux #diretorios #filesystem #fhs

---

## 📌 Visão Geral

O Linux segue o padrão **FHS (Filesystem Hierarchy Standard)**, que define a estrutura de diretórios.

🎯 **Objetivo:** Padronizar a localização de arquivos e diretórios em sistemas Unix-like.

---

## 🌳 Árvore de Diretórios

bash

#### Visualizar árvore (nível 1)

tree -L 1 /

```
**Output:**
```

/ 
├── bin # Binários essenciais
├── boot # Arquivos de boot (kernel, GRUB)
├── dev # Dispositivos (devices)
├── etc # Configurações do sistema
├── home # Diretórios dos usuários
├── lib # Bibliotecas compartilhadas
├── lib64 # Bibliotecas 64-bit
├── media # Pontos de montagem (USB, CD)
├── mnt # Montagens temporárias
├── opt # Software opcional
├── proc # Informações de processos (virtual)
├── root # Home do usuário root
├── run # Dados de runtime
├── sbin # Binários de sistema (root)
├── srv # Dados de serviços
├── sys # Informações do kernel (virtual)
├── tmp # Arquivos temporários
├── usr # Programas e bibliotecas de usuário
└── var # Dados variáveis (logs, cache)

## 📁 Diretórios Principais

### /bin (Binaries)

**Descrição:** Binários essenciais para todos os usuários.

**Exemplos:**
- `ls`, `cat`, `cp`, `mv`, `rm`
- `bash`, `sh`
- `grep`, `sed`, `awk`

### /etc (Et Cetera)

**Descrição:** Arquivos de configuração do sistema.

**Estrutura:**
```

/etc/ ├── passwd # Usuários ├── shadow # Senhas criptografadas ├── group # Grupos ├── hostname # Nome da máquina ├── hosts # Resolução local de nomes ├── fstab # Montagens automáticas ├── crontab # Agendamento de tarefas ├── ssh/ # Configuração SSH ├── apache2/ # Configuração Apache └── network/ # Configuração de rede

```

### /home

**Descrição:** Diretórios pessoais dos usuários.

**Estrutura:**
```

/home/ ├── usuario1/ │ ├── Documents/ │ ├── Downloads/ │ ├── .bashrc # Configuração do Bash │ └── .ssh/ # Chaves SSH └── usuario2/

```
**Atalho:** `~` representa o home do usuário atual.

**Descrição:** Home do usuário **root** (administrador).

**⚠️ Não confundir com `/` (raiz do sistema).**

### /tmp (Temporary)

**Descrição:** Arquivos temporários (apagados no reboot).

**Uso:**
- Cache de aplicativos
- Downloads temporários
- Arquivos de sessão

### /var (Variable)

**Descrição:** Dados variáveis (logs, cache, spool).

**Estrutura:**
```

/var/ ├── log/ # Logs do sistema │ ├── syslog │ ├── auth.log │ ├── apache2/ │ └── mysql/ ├── cache/ # Cache de aplicativos ├── spool/ # Fila de impressão, email ├── tmp/ # Temporários persistentes └── www/ # Arquivos web (Apache)

```
---

### /usr (Unix System Resources)

**Descrição:** Programas e bibliotecas de usuário.

**Estrutura:**
```

/usr/ ├── bin/ # Binários de usuário ├── sbin/ # Binários de sistema ├── lib/ # Bibliotecas ├── local/ # Software instalado localmente │ ├── bin/ │ └── lib/ ├── share/ # Dados compartilhados │ ├── doc/ # Documentação │ └── man/ # Páginas de manual └── src/ # Código-fonte

```
---

### /dev (Devices)

**Descrição:** Arquivos de dispositivos (tudo é arquivo no Linux).

**Exemplos:**
```

/dev/ ├── sda # Primeiro disco (SATA/SCSI) ├── sda1 # Primeira partição ├── sdb # Segundo disco ├── tty # Terminal ├── null # Dispositivo nulo (descarta dados) ├── zero # Dispositivo de zeros └── random # Gerador de números aleatórios

```

### /boot

**Descrição:** Arquivos de inicialização (kernel, GRUB).

**Estrutura:**
```

/boot/ ├── vmlinuz-* # Kernel Linux ├── initrd.img-* # RAM disk inicial └── grub/ # Configuração do GRUB

```
---

### /lib e /lib64

**Descrição:** Bibliotecas compartilhadas essenciais.

**Exemplos:**
- `libc.so` (biblioteca C)
- `libssl.so` (OpenSSL)

---

### /media

**Descrição:** Pontos de montagem automática (USB, CD, DVD).

**Exemplo:**
```

/media/ └── usuario/ └── USB_DRIVE/

```
