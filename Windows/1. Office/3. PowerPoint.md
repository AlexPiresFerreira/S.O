
# PowerPoint — Recursos e construção de slides

## Resumo rápido
- Um bom slide precisa unir:
  - **mensagem**
  - **clareza**
  - **imagens**
  - **tipografia**
  - **cores**
  - **organização visual**
- O objetivo não é encher o slide de informação, mas criar uma apresentação fácil de entender e agradável de ver.
- Storytelling ajuda a transformar conteúdo em narrativa.

---

## 1. Estrutura de um slide bom

### Elementos principais
- **Mensagem**
  - O que você quer comunicar.

- **Slide clean**
  - Pouco texto.
  - Espaço em branco.
  - Foco no essencial.

- **Imagem**
  - Deve reforçar a ideia do slide.
  - Precisa ter boa qualidade.

- **Fontes**
  - Usar poucas fontes.
  - Manter unidade visual.

- **Paleta de cores**
  - Cores coerentes entre si.
  - Facilita leitura e identidade visual.

---

## 2. Storytelling

- **Storytelling** é a construção de uma apresentação como narrativa.
- Ajuda a:
  - prender a atenção;
  - organizar a sequência das ideias;
  - dar sentido à apresentação;
  - conectar início, meio e fim.

### Ideia prática
- Em vez de colocar só dados soltos, conte uma história:
  - problema
  - contexto
  - solução
  - resultado

---

## 3. Tipografia

### Regra básica
- Use **2 ou 3 fontes no máximo**.

### Fontes úteis citadas
- **Bebas Neue**
- **Pacifico**
- **Dr. Brush**
- **Open Sans**
- **Cardo**

### Sites para fontes
- **Google Fonts**  
    [https://fonts.google.com/](https://fonts.google.com/)   
- **DaFont**  
    [https://www.dafont.com/](https://www.dafont.com/)
    
### Boas práticas
- Misture uma fonte de título com uma fonte de texto.
- Evite exagerar no número de estilos.
- Prefira legibilidade.

### Tamanho de texto
- O material cita **12** como referência de texto, mas em slides o ideal é ajustar conforme o contexto para manter leitura confortável.

## 4. Cores

### Ferramenta citada
- **Adobe Color**  
    [https://color.adobe.com/pt/create/color-wheel](https://color.adobe.com/pt/create/color-wheel)

### Para que serve
- Criar **paletas de cores harmoniosas**
- Usar roda cromática
- Testar combinações:
  - complementares
  - análogas
  - triádicas
  - monocromáticas

### Dicas
- Mantenha contraste entre fundo e texto.
- Não use cores demais no mesmo slide.
- Combine a paleta com o tema da apresentação.
